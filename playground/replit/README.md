# Before the workspaces, there were loops

A small archive of my early Replit experiments: shapes, colors and repeated Turtle commands. These belong to the learning trail behind the newer product work.

Twenty source snapshots are preserved here. A twenty-first project had an empty main.py when inspected directly after its export failed. These are learning exercises, not twenty-one launched products.

## Preserve the original, explain the rough edges

The exported main.py files are unchanged. Nineteen parse successfully; TimelyShortCoolingfan contains an incomplete import and does not parse. Parsing is not a GUI execution test. SlipperyCuddlyInsurance defines but never calls its drawing function and contains recursive calls inside it. Several examples reference done without calling it. These limitations are retained rather than hidden.

Five files are byte-identical copies of the Replit Python-with-Turtle starter: OvercookedOffensiveSampler, qq, PrizeAliveModulus, PleasingGlossyUsernames and Python-with-Turtle-Beta. Their template notice remains intact. Presence in my account does not mean every line is original work.

## Running a sketch

Use Python with Tk/Turtle installed and a graphical desktop:

```sh
python3 originals/GreenShinySection/main.py
```

Some archived exercises are incomplete. No web deployment or browser game is claimed. Do not assume that the original Replit workspace URLs are publicly accessible.

## Verify the snapshots

```sh
python3 verify.py
```

The verifier checks each archived source against its recorded SHA-256 and expected syntax status. It does not open a GUI. Configuration, cookies, environment files, virtual environments, platform drivers and Git internals are excluded from this public archive.
